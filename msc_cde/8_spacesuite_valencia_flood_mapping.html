Flood Mapping of Valencia, France using SAR Data

In late October 2024, Spain faced one of its most catastrophic floods in decades, severely affecting the Valencia region and surrounding areas. The disaster claimed over 200 lives, displaced thousands, and caused widespread destruction to infrastructure and livelihoods.

I am sharing the results obtained from hands-on training provided by SpaceSUITE.

Following are the steps carried out in SNAP tool to do flood mapping.

1. Import GRD SAR Image

Pre-event (2024-10-07), During-event (2024-10-19) and post-event (2024-10-31) images were provided for the study area. But the Sentinel-1 images can be easily downloaded from https://dataspace.copernicus.eu/explore-data or https://search.asf.alaska.edu/

Figure 1: Pre, during and post flood event SAR images Load in SNAP



2. Subsetting

For flood mapping, VV polarization is more critical than VH, which is primarily used for vegetation analysis. Therefore, this process is done to save only VV bands.

Tool: Raster >> Subset

Figure 3: Subset Image

3. Orbit File Application

In this step, an orbit file is applied to SAR products to establish a connection between the image coordinates and their corresponding ground locations.

Tool: Radar>> Apply orbit file

Figure 5: Orbit File IO Parameters

Figure 6: Orbit File Processing Parameters



4. Radiometric Calibration

In this process, the original image pixel values, which are derived as digital numbers (DNs) are converted into actual radar backscatter. This means, that the data is manipulated in a way that provides imagery with pixel values that can be directly related to the radar backscatter of the scene.

Tool: Radar>Radiometric>Calibrate

Figure 7: Radiomentric Calibration Result



5. Speckle Filtering

Speckle filtering is a very important step in the preprocessing chain of SAR imagery. The choice of the type of filter that is used to remove speckle effects strongly depends on the application and the study site. For this study area, Lee filter was selected. The SigmaO_VV bands were then converted into the decibel by right clicking in the layer and selecting the Liner to/from db option. The decibel values are logarithmic and it leads to more contrast in the resulting image, as stronger backscatter values shift towards the mean and darker values get stretched stronger.

Radar>> Speckle Filtering>> Single product speckle filter

6. Terrain Correction

This process is carried out to map the image into a desired coordinate system. In this case study, default WGS84 was selected. If we comapare the output to the Figure 9, the image has been flipped upside down. The bands were then converted into the decibel and visualize the output.

Tool: Radar >> geometric >> terrain correction >> range doppler terrain correction

7. Stacking

This process is carried out to stack bands of different time in one image. The bands were then again converted into the decibel.

Tool: Radar >> coregistration >> stack tool >> create stack

8. Spatial Subset

Spatial subset is carried out to extract area of interest. For this, adjust and resize the blue bounding box to fit the study area.

Tool: Raster >> Subset

Figure 13: Spatial subset selection

Tool: window>>open RGB Image

Select the Red, Green and Blue bands as shown in figure below and run it.
